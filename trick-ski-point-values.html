Water ski trick point values

A trick run is two 20-second passes. Every trick you land is worth a set number of points, each trick scores only once (plus once more as its reverse), and your score is the total from both passes. On one ski, a side slide is worth 40, a wake 360 is 150 and a backward wake flip is 500.

How a trick run scores

Under the IWWF Waterski Rules 2026 (Rule 9), each trick has a code and a value. The value depends on whether you're on two skis or one, and the reverse, the same trick turned the other way, has its own value. A reverse only counts if it comes right after its basic in the same pass, though 180s are allowed in between. A repeat scores zero, a trick you fall on or don't finish before the end of the pass scores zero, and only six flips count in a run.

How to read a trick run

Judges write a run as a list of codes in order, like S, RS, B, F, WB, WF for a one-ski pass. Look up each code in the chart for your number of skis and add them up. On one ski that pass is 40 + 40 + 60 + 60 + 80 + 80 = 360. If the same code shows up twice, only the first one counts. A code with R in front, like RS, is the reverse and uses the R value.

Your tournament may run under a different rulebook, so check its rules for anything official.
